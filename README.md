# Tomorrow

A cozy story-puzzle game made in Unity 6: *Borrow from tomorrow. Build it today. Give it back by sunset.*

This repository holds **only the code**:

| Folder | What's in it |
|---|---|
| `Assets/Game/Scripts` | Game code (C#): the chapter stories, the loan rules, player, camera, UI, music and sound |
| `Assets/Game/Editor` | Editor code that builds every scene, plus the build menus |
| `Tools` | Python tools that generate the voices, music, logo and buildings |
| `Packages`, `ProjectSettings` | The Unity package list and project settings |

The 3D models, audio, images, fonts and scenes are **not** in this repository. To run the game, use the full project, which is kept outside git.

See `Assets/Game/README.md` for how everything works.
